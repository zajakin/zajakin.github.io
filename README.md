# Zajakin BioTools

Lightweight, lightning-fast, and 100% portable open-source desktop GUI software for modern molecular biology and bioinformatics.

---

## 🧬 ChromaZ — Contig Alignment Viewer & Chromatogram Editor

A modern desktop replacement for bloated suites, built for high-precision trace analysis. 

*   **7+ Independent Alignment Algorithms:** Includes OLC/CAP3 (Sanger default), Gotoh, Smith-Waterman, and Wavefront Alignment (WFA).
*   **Chromatogram Plot & Phred QC:** Beautiful 4-color trace plots with automated low-quality end-trimming.
*   **Advanced Analysis:** REBASE restriction enzyme integration, 1-click UniVec vector trimming, and 6-frame ORF translation.
*   **Audio Dictation (TTS):** Voice readout for hands-free sequence proofreading against physical lab notes.

👉 [**Get ChromaZ on GitHub**](https://github.com)

## 🗺️ LiftOverZ — Genomic Coordinates Assembly Converter

Ditch the command line. Run full VCF/BED genome liftovers locally with complete biological validation.

*   **Pre-bundled Chain Presets:** Embedded human (hg19, hg38, T2T-CHM13v2) and mouse builds running right out of the box.
*   **Mitochondrial Fixes:** Custom gap-free mitochondrial alignments based on GATK standards to prevent dropped variants.
*   **Strict FASTA Validation:** Automated management of strand inversions (Strand Flips) and allele swaps (REF/ALT Swap) using target FASTA.
*   **6 Major Formats Supported:** Native drag-and-drop processing for VCF, gVCF, BED, GFF/GTF, Wiggle, and MAF.

👉 [**Get LiftOverZ on GitHub**](https://github.com)
