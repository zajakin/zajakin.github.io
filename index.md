## 💻 Flagship Desktop Applications (GUI)

### 🧬 ChromaZ — Contig Alignment Viewer & Chromatogram Editor
A lightweight, modern C++/Qt6 desktop alternative to bloated sequencing suites, built for high-precision trace analysis.
*   **7+ Alignment Algorithms:** Built-in OLC/CAP3 (Sanger default), Gotoh, Smith-Waterman, and Wavefront Alignment (WFA).
*   **Trace Analysis:** Beautiful 4-color chromatogram plots (`.ab1`, `.scf`) with automated quality trimming.
*   **Lab Utilities:** REBASE restriction mapping, UniVec vector trimming, and 6-frame ORF translation.
*   **Audio Proofreading:** Text-to-Speech (TTS) voice readout to verify sequences hands-free against paper notes.
*   📦 [Get ChromaZ on GitHub](https://github.com/zajakin/ChromaZ)

### 🗺️ LiftOverZ — Standalone Genomic Coordinates Converter
Ditch the command-line bottlenecks. Perform fast, local coordinate conversions with complete biological validation.
*   **Pre-bundled Chains:** Direct support for human (hg19, hg38, T2T) and mouse builds.
*   **Mitochondrial Alignment Fixes:** Custom gap-free mitochondrial chains preventing lost variants on `chrM`.
*   **Biological Auditing:** Optional target FASTA reference validation for strand flips and REF/ALT swaps.
*   📦 [Get LiftOverZ on GitHub](https://github.com/zajakin/LiftOverZ)

## 🧪 Bioinformatics Pipelines & Data Analysis

### 📊 sRNAflow — Small RNA-seq Analysis Pipeline
A robust tool designed for comprehensive end-to-end processing and analysis of small RNA sequencing data.
*   Optimized for microRNA (miRNA) and small non-coding RNA profiling.

*   📦 [Get sRNAflow on GitHub](https://github.com/zajakin/sRNAflow)

### 🐳 Docker-BioInf — Multi-Container Gen Platform
An automated infrastructure system for generating multiple isolated Docker environments.
